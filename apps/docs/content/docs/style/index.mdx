## Deprecated

  Coolify caught up. [v4.3](https://github.com/coollabsio/coolify/releases/tag/v4.3.0) redesigned the whole interface, and [v4.5.1](https://github.com/coollabsio/coolify/releases/tag/v4.5.1) added built-in custom themes with presets and share codes.

## Overview

Coolify Tweaks is A theme that refines spacing, typography, and colors. It keeps the interface familiar while smoothing out rough edges, making everything feel more intentional without rebuilding the UI.

You can check out the [screenshots](/docs/style/screenshots) page to see the difference between the original and the tweaked version.

> Coolify Tweaks is not affiliated with Coolify or its developers. It is a standalone project that styles the dashboard on your behalf.

## How does it work?

There are two supported install paths today:

- **Stylus (browser extension)** injects the CSS on load, so every refresh floats the themed styles right on top of Coolify.
- **Dynamic Config (Traefik rewrite)** rewrites Coolify's HTML responses, which means every browser and device hitting your dashboard picks up the tweak without installing anything extra.
